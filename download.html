Package

패키지 구성

6개 파일로 완성되는 디자인 시스템

Claude 슬래시 커맨드
.claude/commands/canb-dashboard.md

/canb-dashboard 명령 한 번으로 디자인 시스템 전체 규칙을 Claude에 즉시 주입합니다.

디자인 토큰
styles/tokens.css

색상, 간격, 타이포그래피, 그림자를 CSS 변수로 정의합니다. 라이트/다크 모드를 모두 지원합니다.

컴포넌트 스타일
styles/common.css

카드, 버튼, 테이블, 배지, 사이드바, 필터바 등 모든 UI 컴포넌트 스타일이 담겨 있습니다.

차트 유틸리티
js/utils.js

Chart.js 기본값 설정, 라이트/다크 색상 전환, 날짜·숫자·퍼센트 포맷 함수가 포함됩니다.

레이아웃 엔진
js/layout.js

사이드바 렌더링, 테마 토글, 브레드크럼, 커스텀 셀렉트를 initLayout() 한 줄로 초기화합니다.

디자인 시스템 문서
DESIGN SYSTEM.MD

색상 스케일, 컴포넌트 스펙, 배지·버튼·차트 사용 규칙이 담긴 전체 레퍼런스 문서입니다.

Features

주요 특징

처음부터 끝까지 일관된 개발 경험을 제공합니다

CANB Magenta 브랜드
#BC216D 기반 투명도 단계 차트 컬러 시스템. 색상 결정에 드는 시간을 없앱니다.
라이트 / 다크 모드
CSS 변수 기반으로 두 모드를 완벽 지원. 토글 버튼이 자동 삽입되며 상태가 localStorage에 저장됩니다.
Chart.js 통합
막대·라인·도넛·폴라 차트가 테마에 따라 자동으로 색상을 전환합니다. 두께·점 스타일 사전 설정 포함.
완성형 컴포넌트
카드, 테이블, 배지, 버튼, 모달, 필터바, 진행률 바 등 즉시 사용 가능한 컴포넌트가 모두 포함됩니다.
Vanilla JS · 빌드 불필요
Node.js, 번들러, 패키지 설치 없이 브라우저에서 바로 실행됩니다. CDN 링크 4줄로 시작합니다.
Claude 슬래시 커맨드
/canb-dashboard 한 번으로 디자인 규칙 전체를 Claude에 전달. 규칙 설명 없이 바로 개발을 시작합니다.

Quick Start

3단계로 시작하기

복잡한 설치 없이 파일만 복사하면 됩니다

1
ZIP 다운로드 후 압축 해제

다운로드한 ZIP을 원하는 위치에 압축 해제하세요. 6개 파일이 포함되어 있습니다.

canb-dashboard-kit/
├─ .claude/commands/
│ └─ canb-dashboard.md
├─ styles/
│ ├─ tokens.css
│ └─ common.css
├─ js/
│ ├─ utils.js
│ └─ layout.js
└─ DESIGN SYSTEM.MD
2
슬래시 커맨드 등록

Claude Code 프로젝트 루트에 .claude/commands/ 폴더를 만들고 커맨드 파일을 복사합니다.

# Windows
%USERPROFILE%\.claude\
  commands\canb-dashboard.md

# Mac / Linux
~/.claude/commands/
  canb-dashboard.md
3
기반 파일 복사 후 시작

새 프로젝트에 styles/, js/ 폴더를 복사하고 Claude에서 /canb-dashboard를 입력하세요.

# Claude Code에서
/canb-dashboard

# 그런 다음 요청
"수납 관리 페이지 만들어줘"
