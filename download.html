시작하기

3단계 설치 가이드

ZIP을 받고 3단계만 따라하면 바로 사용할 수 있습니다.

1

ZIP 다운로드 및 압축 해제

아래 버튼을 눌러 canb-dashboard-kit.zip을 받고 원하는 위치에 압축을 해제합니다.

canb-dashboard-kit.zip 다운로드
2

Claude 슬래시 커맨드 등록

claude-skill/canb-dashboard.md를 Claude 글로벌 커맨드 폴더에 복사합니다.

# Windows
C:\Users\{사용자명}\.claude\commands\canb-dashboard.md

# Mac / Linux
~/.claude/commands/canb-dashboard.md
3

새 프로젝트에 베이스 파일 복사

새 대시보드 프로젝트 폴더에 styles/, js/, DESIGN SYSTEM.MD를 그대로 복사합니다.

# 새 프로젝트 구조
my-dashboard/
├── styles/tokens.css
├── styles/common.css
├── js/utils.js
├── js/layout.js
└── DESIGN SYSTEM.MD

Claude Code를 해당 폴더에서 열고 슬래시 커맨드를 입력합니다.

/canb-dashboard
