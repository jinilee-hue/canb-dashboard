기본 모달

정보 표시, 상세 보기 등 일반적인 용도의 기본 모달입니다.

폼 모달

입력 폼이 포함된 모달입니다. 등록·수정 작업에 사용합니다.

확인 모달 (소형)

동작 확인 요청 모달입니다. .modal-sm 사용.

삭제 확인 모달

삭제·취소 등 비가역적 동작에 대한 경고 확인 모달입니다.

대형 모달

넓은 콘텐츠가 필요한 경우. .modal-lg 사용.

날짜 피커

Flatpickr 기반 날짜 선택 컴포넌트. 단일·범위 두 가지 모드 제공.

하단 탭바

방문 페이지가 탭으로 쌓입니다. 탭이 많아지면 가로 스크롤이 생깁니다.

커스텀 셀렉트

filter-select 클래스 사용 시 자동으로 커스텀 드롭다운으로 변환됩니다.

토스트 메시지
Success

완료·저장·등록 성공 시 사용합니다.

Warning

주의·미납·경고 상황에 사용합니다.

Danger

삭제 실패·오류 발생 시 사용합니다.

Info

일반 안내·정보 전달에 사용합니다.

JavaScript API

showToast(message, type, duration)

// type: 'success' | 'warning' | 'danger' | 'info'
// duration: ms (기본 3500, 0 = 유지)

showToast('저장되었습니다.', 'success');
showToast('미납 내역이 있습니다.', 'warning');
showToast('오류가 발생했습니다.', 'danger');
showToast('공지가 등록되었습니다.', 'info', 5000);
